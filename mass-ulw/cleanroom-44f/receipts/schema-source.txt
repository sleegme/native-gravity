name:    name    string    (Required)   The unique identifier for the custom agent.  
description:    description    string    (Required)   Detailed description used by the planner to determine when to delegate tasks to this agent.  
tools:    tools    string[]    []   Explicit list of tools permitted for this subagent (e.g.  view_file ,  replace_file_content ,  grep_search ,  run_command ).  
mainAgent:    mainAgent    boolean    true   If  true , allows selection as the primary agent in chat interfaces.  
subagent:    subagent    boolean    true   If  true , allows invocation via the  invoke_subagent  tool.  
model:    model    string    inherit   Model tier used when invoked ( inherit ,  flash , or  pro ).  
commandExecutionPolicy:    commandExecutionPolicy    string    sandbox   Auto-execution policy for shell commands ( off ,  auto ,  eager ,  sandbox ).  
mcpServers:    mcpServers    object[]    []   Custom Model Context Protocol servers configured for this subagent.  
skills:    skills  /  plugins    string[]    []   Skill paths (e.g.  skills/my-helper-skill ) or plugin dependencies.  
plugins:    skills  /  plugins    string[]    []   Skill paths (e.g.  skills/my-helper-skill ) or plugin dependencies.
