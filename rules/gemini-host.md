# Gemini Host correction loader

This rule keeps Gemini Host corrections separate from the generic Native Gravity Host policy.

When the Antigravity Default Host is Gemini 3.7 Flash High, apply the referenced v0.3.2 correction in addition to `harness.md` and `orchestration.md`.

For other Host models, the referenced rules are non-applicable and must not change the generic orchestration contract.
